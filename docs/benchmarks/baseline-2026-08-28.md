# Gaze core baseline (synthetic, 1920x1080, 35 fps)

Generated by `bun run tools/bench/gaze-bench.ts` against the shipped
`src/lib/gaze/calibration.ts` and `src/lib/gaze/filter.ts`, driven by the
deterministic simulator in `tools/bench/simulator.ts` (fixed seed, reproducible).

**How to read this.** Absolute pixel values depend on the simulator's noise and
eye-model assumptions and are not a claim about real-world accuracy. The
comparisons between rows are the result. Analysis: [`../analysis/03-tracking-and-jitter.md`](../analysis/03-tracking-and-jitter.md).

- *fixation jitter* — RMS spread of the cursor while the simulated gaze is held
  on a single point.
- *latency* — lag of the filtered series against the raw predicted series,
  measured by cross-correlation alignment; it isolates filter delay from model
  bias, so `0.0 ms` means "this filter is not delaying the signal", not "this
  system has no latency".
- *settle* — time for the filtered cursor to reach its own steady state after a
  saccade.
- *tracking err* — absolute error against ground truth, including calibration
  bias.
